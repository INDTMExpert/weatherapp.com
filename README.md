🌦️ Weather App

A simple and responsive Weather Application built using HTML, Bootstrap, and JavaScript that fetches real-time weather data using the Open-Meteo API.

🚀 Features
🔍 Search weather by city name
🌡️ Real-time temperature display
💧 Humidity information
🌬️ Wind speed & direction
🌅 Sunrise & 🌇 Sunset timings
📱 Fully responsive UI using Bootstrap
⚡ Fast and lightweight (No API key required)
🛠️ Tech Stack
HTML5
CSS (Bootstrap 5)
JavaScript (Vanilla JS)
Open-Meteo API (Free & No API Key Required)
📂 Project Structure
📁 Weather-App
│── index.html      # Main UI
│── weather.js      # Logic & API handling
⚙️ How It Works
User enters a city name.
App fetches coordinates using Geocoding API.
Then it fetches weather data using Open-Meteo API.
Data is displayed dynamically on the UI.
🧠 Key Concepts Used
Fetch API (Async/Await)
DOM Manipulation
Event Handling
API Integration
Time Formatting
